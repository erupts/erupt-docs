# 可视化分析

从维度指标到可交互仪表盘，全程拖拽完成，无需编写前端代码。Erupt Cube 提供完整的 BI 分析能力，支持多图表类型、多维过滤器与灵活的栅格布局系统。

## 仪表盘概览

基于语义模型构建的订单分析仪表盘，展示核心指标卡、柱状图、饼图与折线图的典型布局。

## 拖拽构建流程

将字段面板中的维度或指标拖入画布，即时生成对应图表，整个过程无需配置代码。

1. **拖入维度字段** — 从左侧字段面板选取维度（如渠道、城市、日期），拖入图表 X 轴或分组区域。
2. **拖入指标字段** — 选取数值指标（如订单量、收入）拖入 Y 轴或值区域，图表自动刷新并展示聚合结果。
3. **切换图表类型** — 点击图表右上角的类型切换按钮，可在柱状图、折线图、饼图等类型间一键切换，无需重新配置。
4. **调整布局与尺寸** — 在栅格系统中拖动图表卡片调整位置，拖动边角调整占比大小，保存后即发布为正式仪表盘。

## 图表类型

开箱即用，覆盖常见业务分析场景，无需额外安装插件。

| 图表类型 | 适用场景 |
| --- | --- |
| 📊 柱状图 | 分类对比、排名分析 |
| 📈 折线图 | 趋势变化、时序分析 |
| 🥧 饼图 | 占比结构、品类拆分 |
| 🔵 散点图 | 相关性、分布分析 |
| 📉 面积图 | 累计量、堆叠趋势 |
| 🟦 热力图 | 密度分布、交叉分析 |
| ⬜ 表格 | 明细数据、多维对比 |
| 🔢 KPI 卡片 | 核心指标、环比趋势 |

## 过滤器类型

多种过滤器组件，支持联动过滤，所有图表响应同一过滤器上下文。

| 过滤器 | 说明 |
| --- | --- |
| 🔽 下拉选择 | 单值枚举筛选 |
| 📅 日期范围 | 起止日期区间 |
| 🔢 数值区间 | 最大/最小值限定 |
| 🔍 模糊搜索 | 关键词匹配 |
| ☑️ 多选 | 多值 IN 过滤 |
| 🔘 单选 | 互斥选项切换 |
| 📆 相对时间 | 近 7 天 / 本月等预设 |

## 使用前提

可视化功能依赖语义模型层，建议按以下顺序完成配置：

1. **[接入数据源](/zh/modules/pro/erupt-cube/datasource)** — 在「数据源」模块完成 JDBC 数据库连接配置（MySQL、ClickHouse、PostgreSQL 等）。
2. **[定义语义模型](/zh/modules/pro/erupt-cube/semantic-model)** — 在「语义层」中配置维度、指标、SQL 模板，为图表提供业务化字段描述。
3. **创建仪表盘** — 进入「仪表盘」模块，点击「新建」后即可通过拖拽方式自由构建可视化看板。
