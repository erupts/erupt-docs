# 界面与交互

Erupt 的界面由注解生成，但**用起来顺不顺手**不靠注解——下面这些能力开箱即有，无需任何配置，且大多按用户、按模型记在浏览器本地，下次打开还是你上次的样子。

## 外观设置

点击右上角 ⚙️ 打开 **页面配置** 抽屉，所有改动实时生效：

![页面配置](/ui/page-config.png)

### 外观

| 配置 | 说明 |
| --- | --- |
| 主题色 | 18 色预设 + 自定义取色器，一键重置回默认 `rgb(22, 119, 255)` |
| 顶栏色 | 跟随主题 / 跟随主题色 / 预设色 / 自定义取色器 |
| 配色方案 | 浅色 / 深色 / 跟随系统（跟随系统随 OS 实时切换） |
| 紧凑模式 | 缩小控件间距，一屏放下更多内容，可与深色任意组合 |
| 皮肤 | 默认 / Brutalist / Liquid Glass（液态玻璃）/ Workspace / Classic，五者互斥；2.3.0 起选择器改为带缩略图的平铺网格 <Badge type="tip" text="v2.3.0+" /> |

其中两款皮肤为 2.3.0 新增 <Badge type="tip" text="v2.3.0+" />：

- **Workspace**：Slack / 飞书 / 钉钉式的工作台外壳——顶栏与侧边栏共用一块品牌色调的框架，内容区以圆角卡片浮在其上。框架配色有 32 套浅色 / 深色预设（浅色框架会自动把导航文字翻成墨色），站点默认值由 `theme.workspaceFrame` 指定，不设则从主题色推导；登录页在此皮肤下也套用同一框架
- **Classic**：Ant Design Pro 经典外壳——深蓝侧边栏 + 白色顶栏，顶部菜单模式下深蓝转移到顶栏

### 其他

色弱模式、灰度模式（哀悼日常用）、RTL 从右向左布局、一键清除本地缓存。

:::tip 默认值与个人选择
`app.js` 中的 `theme`（`primaryColor`、`headerColor`、`dark`、`compact`、`skin`、`workspaceFrame`、`menuMode`、`formPanelMode`、`loginLayout`）和 `tabReuse` 是**系统默认值**，见 [前端配置](/zh/guide/config-frontend)；用户在此抽屉里的选择保存在浏览器 localStorage 中并优先生效。清除缓存即回到系统默认；`theme.customizable: false` 则让品牌相关项不再接受用户选择。

## 登录页布局 <Badge type="tip" text="v2.3.0+" />

登录页提供五种布局，可在登录页顶部导航中切换（选择保存在浏览器 localStorage 的 `login-layout` 中；`theme.customizable: false` 时隐藏切换入口），站点默认值由 `app.js` 的 `theme.loginLayout` 指定：

| 布局 | 值 | 说明 |
| --- | --- | --- |
| 居中卡片 | `center` | 登录卡片居中浮在插画之上（默认） |
| 侧边面板 | `cover` | 插画铺满全屏，表单停靠右侧的 440px 面板 |
| 宽卡分栏 | `wide` | 一张 800px 宽卡，左侧品牌区（Logo 在上、标题在下），右侧表单 |
| 壁纸玻璃 | `wallpaper` | 图片铺满全屏，中间一张毛玻璃卡片 |
| 品牌满屏 | `poster` | 品牌名作为海报级大标题，小卡片位于右下角 |


居中卡片（`center`）与侧边面板（`cover`），均配置了 `theme.loginBackground` 自定义登录图片：

![登录页：居中卡片](/ui/login-center.png)

![登录页：侧边面板](/ui/login-cover.png)

- 窗口宽度小于 992px 时所有布局都收拢为居中卡片
- `theme.loginBackground` 可指定一张图片替换所有布局中的默认插画（自动加暗角保证品牌与版权可读）；图片加载失败时回落到默认插画，不会出现空白页
- Workspace 皮肤下登录页套用与工作台相同的框架配色
- 安装 [erupt-sso](/zh/modules/erupt-sso) 后，登录卡片自动出现单点登录按钮：3 个以内的认证源横排显示名称，更多则收为带提示的圆形图标

| --- | --- | --- |

## 表格能力

![表格列配置](/ui/table-columns.png)

### 列控制

点击表格工具栏的 ▦ 按钮打开列面板：

- **显隐**：勾选控制每列是否展示
- **排序**：拖拽左侧手柄调整列顺序
- **固定**：图钉按钮在「固定左侧 → 固定右侧 → 不固定」间循环
- **列宽**：直接拖拽表头分隔线调整，面板底部「重置列宽」一键还原

以上设置**按模型**保存在本地，换页面互不影响。

### 工具栏

| 功能 | 说明 |
| --- | --- |
| 刷新 / 自动刷新 | 手动刷新，或设置 10s / 30s / 1min / 5min 自动刷新，开启时按钮高亮 |
| 全屏 | 表格区域全屏展示 |
| 查询 | 展开 / 收起搜索区，搜索条件与操作符按模型记忆 |
| 排序 | 多字段排序配置 |
| 打印布局 | 打印当前行或按模板输出 |
| 导入 / 导出 | Excel 导入、导出、下载模板（需 `@Power` 开启） |
| 复制行 | 选中一行后一键复制为新增表单，主键已清空，适合录入结构相近的数据 |
| 重置 | 清空搜索条件恢复初始状态 |
| AI | 打开右侧 AI 助手面板，对当前模型提问 |

### 搜索与视图

- **操作符可切换**：搜索区每个字段前有操作符下拉（等于 / 模糊 / 大于 / 区间 / 多选等），选择按模型记忆；服务端可用 [@Search(lockOperator)](/zh/annotation/search) 锁死不允许切换
- **多视图**：同一模型可配置表格之外的[看板](/zh/annotation/vis-board)、[日历](/zh/annotation/vis-calendar)、[卡片](/zh/annotation/vis-card)、[甘特图](/zh/annotation/vis-gantt)，顶部切换，当前视图按模型记住
- **树表联动**：[@LinkTree](/zh/annotation/link-tree) 配置后左侧出现树形导航，点击节点过滤右侧表格，树面板可拖拽宽度、可整体折叠

### 单元格呈现

表格单元格按 [@View(type)](/zh/annotation/view) 渲染，其中这些是可交互的：图片点击放大预览、附件弹层查看与下载、二维码、进度条、颜色块、Markdown / HTML 富文本、布尔与选择项标签；超长文本自动省略，悬浮查看完整内容。

2.3.0 起 <Badge type="tip" text="v2.3.0+" />：

- **头像列**：`@View(type = ViewType.AVATAR)` 渲染 32px 圆形缩略图（详情页 120px），为空时显示人形占位，用户表的头像即以此方式展示
- **单元格换行**：模型配置 [@Layout(tableTruncate = false)](/zh/annotation/layout#tabletruncate-单元格换行) 后，超出列宽的内容换行显示而不是省略号，操作列按钮再多也全部可见
- **空布尔值**：布尔字段为 null 时单元格留空，不再渲染一个空标签

### 多维表格编辑 <Badge type="tip" text="v2.2.0+" />

双击单元格（或点击单元格上的编辑图标）即可就地修改一个字段，不必打开行表单——像用多维表格一样改数据。

![单元格编辑](/ui/cell-edit.png)

- **就是表单里那套组件**：浮层用的是行表单同一个编辑组件，值转换、校验、引用选择器行为完全一致，复制按钮、AI 写作助手、字数统计一并具备
- **整行校验**：服务端把库中原始行打上新值后**按整行校验**，跨字段的规则不会被逐格改写绕过，`DataProxy` 与操作日志和表单提交一致
- **两级开关**：模型级 `@Power(cellEdit)`、字段级 `@Edit(cellEdit)`，账号、角色编码、密钥这类字段框架已默认关闭

详见 [@Power → cellEdit 单元格编辑](/zh/annotation/power#celledit-单元格编辑)。

### 行内交互

- **拖拽排序**：模型配置 [@DragSort](/zh/annotation/drag-sort) 后，行首出现拖拽手柄，直接拖动调整顺序并保存
- **行操作**：查看、编辑、删除与自定义 [@RowOperation](/zh/annotation/row-operation) 按钮
- **分页记忆**：每页条数、当前视图（表格 / 卡片 / 甘特等）按模型记住

::: details 每个模型在本地记住了什么
浏览器 localStorage 中以 `erupt.<模型名>` 为键保存：

| 字段 | 含义 |
| --- | --- |
| `columns` | 各列的显隐、宽度、固定位置 |
| `columnOrder` | 列顺序 |
| `treeWidth` / `treeCollapsed` | 左侧树宽度与折叠状态 |
| `aiPanelOpen` / `aiPanelWidth` | AI 面板开关与宽度 |
| `searchCollapsed` / `searchFieldsCollapsed` / `searchOperators` | 搜索区折叠状态与各字段选用的操作符 |
| `pageSize` | 每页条数 |
| `visIndex` | 当前视图索引 |

这些只存在于当前浏览器，不会上传服务端，也不影响其他用户。
:::

## 弹窗与表单

![可拖拽弹窗](/ui/draggable-modal.png)

- **弹窗可拖拽**：新增 / 编辑、引用选择、子表、附件选择等全部弹窗均可按住标题栏拖动，挪开后仍能看到底层表格数据对照填写
- **[分步表单](/zh/annotation/form-steps)**：字段多时按 DIVIDE 分割线拆成向导式步骤
- **输入辅助**：输入框左侧一键复制当前值，右侧是 [表单 AI 写作助手](/zh/modules/erupt-ai/writing-assistant)，下方实时显示字数 / 上限
- **代码与富文本**：代码编辑器、Markdown、富文本均支持全屏编辑与复制
- **附件拖拽**：多附件字段可拖拽调整顺序

### 表单面板 <Badge type="tip" text="v2.3.0+" />

新增 / 编辑 / 查看记录的表单统一为一个**表单面板**，有三种形态，可在面板标题栏或页面配置抽屉的「详情弹窗形态」中切换，切换时已加载的表单与未保存的输入原样保留：

| 形态 | 值 | 说明 |
| --- | --- | --- |
| 中间弹窗 | `center` | 居中浮动对话框，可拖拽（默认） |
| 侧边面板 | `side` | 停靠右侧的面板，宽度可拖拽并记忆（整行布局的表单单独记忆）；查看态下不遮挡列表点击，切换记录时面板复用 |
| 全屏 | `full` | 占满整个窗口，适合字段多、带子表的表单 |

站点默认值由 `app.js` 的 `theme.formPanelMode` 指定，用户的选择保存在浏览器中并优先生效。

标题栏集中了对当前记录的操作：

- **上一条 / 下一条**：在列表范围内逐条浏览并显示「n / 总数」，到边界时自动翻页
- **查看 ↔ 编辑**：就地切换，不必关掉再打开
- **复制链接**：复制带 `?id=<主键>` 的深链接，打开该表格路由时自动弹出这条记录的面板（多标签页复用已打开的标签时同样生效）
- **删除**：气泡确认后删除当前记录，面板跳到相邻记录或关闭
- **AI 助手**：以当前模块与记录值为上下文打开 AI 对话（需 [erupt-ai](/zh/modules/erupt-ai/)）
- **更多**：打印（需 [erupt-print](/zh/modules/erupt-print)，且模型未以 `@Power(print = false)` 关闭）
- **评论**：打开这条记录的评论流（需 [erupt-comment](/zh/modules/erupt-comment)）

关闭面板、切换记录或退出编辑时，若有未保存的修改会先询问是否放弃。**点击行查看详情**默认关闭——整行是一个很大的点击目标，上面还有链接、按钮与可编辑单元格；在页面配置抽屉中开启后，点击表格行即打开该记录的详情面板，行上显示手形光标，链接、按钮与可编辑单元格保留自己的行为。

## 抽屉 <Badge type="tip" text="v2.3.0+" />

全站抽屉统一为 44px 高的标题栏（与页面头部等高）：标题居左，关闭按钮为右侧小方块。AI 对话、通知中心、Cube 下钻、流程发起、流程图、TPL 模板、审批详情等抽屉均可拖拽内侧边缘调整宽度，并各自记住上次拖到的尺寸。

## 锁屏与个人资料 <Badge type="tip" text="v2.3.0+" />

顶栏头像菜单新增三项：**个人信息**（修改自己的头像与昵称，保存后顶栏即时更新）、**双因素认证**（绑定 TOTP 动态口令）与**锁屏**（整窗遮罩盖住当前页面，标签页保持原样，输入密码解锁，刷新页面仍保持锁定）。个人信息与锁屏仅对平台账号显示，租户会话不显示。详见 [用户管理 → 个人资料与锁屏](/zh/modules/erupt-upms/user#个人资料与锁屏)。

## 表格能力

![表格列配置](/ui/table-columns.png)

### 列控制

点击表格工具栏的 ▦ 按钮打开列面板：

- **显隐**：勾选控制每列是否展示
- **排序**：拖拽左侧手柄调整列顺序
- **固定**：图钉按钮在「固定左侧 → 固定右侧 → 不固定」间循环
- **列宽**：直接拖拽表头分隔线调整，面板底部「重置列宽」一键还原

以上设置**按模型**保存在本地，换页面互不影响。

### 工具栏

| 功能 | 说明 |
| --- | --- |
| 刷新 / 自动刷新 | 手动刷新，或设置 10s / 30s / 1min / 5min 自动刷新，开启时按钮高亮 |
| 全屏 | 表格区域全屏展示 |
| 查询 | 展开 / 收起搜索区，搜索条件与操作符按模型记忆 |
| 排序 | 多字段排序配置 |
| 打印布局 | 打印当前行或按模板输出 |
| 导入 / 导出 | Excel 导入、导出、下载模板（需 `@Power` 开启） |
| 复制行 | 选中一行后一键复制为新增表单，主键已清空，适合录入结构相近的数据 |
| 重置 | 清空搜索条件恢复初始状态 |
| AI | 打开右侧 AI 助手面板，对当前模型提问 |

### 搜索与视图

- **操作符可切换**：搜索区每个字段前有操作符下拉（等于 / 模糊 / 大于 / 区间 / 多选等），选择按模型记忆；服务端可用 [@Search(lockOperator)](/zh/annotation/search) 锁死不允许切换
- **多视图**：同一模型可配置表格之外的[看板](/zh/annotation/vis-board)、[日历](/zh/annotation/vis-calendar)、[卡片](/zh/annotation/vis-card)、[甘特图](/zh/annotation/vis-gantt)，顶部切换，当前视图按模型记住
- **树表联动**：[@LinkTree](/zh/annotation/link-tree) 配置后左侧出现树形导航，点击节点过滤右侧表格，树面板可拖拽宽度、可整体折叠

### 单元格呈现

表格单元格按 [@View(type)](/zh/annotation/view) 渲染，其中这些是可交互的：图片点击放大预览、附件弹层查看与下载、二维码、进度条、颜色块、Markdown / HTML 富文本、布尔与选择项标签；超长文本自动省略，悬浮查看完整内容。

2.3.0 起 <Badge type="tip" text="v2.3.0+" />：

- **头像列**：`@View(type = ViewType.AVATAR)` 渲染 32px 圆形缩略图（详情页 120px），为空时显示人形占位，用户表的头像即以此方式展示
- **单元格换行**：模型配置 [@Layout(tableTruncate = false)](/zh/annotation/layout#tabletruncate-单元格换行) 后，超出列宽的内容换行显示而不是省略号，操作列按钮再多也全部可见
- **空布尔值**：布尔字段为 null 时单元格留空，不再渲染一个空标签

### 多维表格编辑 <Badge type="tip" text="v2.2.0+" />

双击单元格（或点击单元格上的编辑图标）即可就地修改一个字段，不必打开行表单——像用多维表格一样改数据。

![单元格编辑](/ui/cell-edit.png)

- **就是表单里那套组件**：浮层用的是行表单同一个编辑组件，值转换、校验、引用选择器行为完全一致，复制按钮、AI 写作助手、字数统计一并具备
- **整行校验**：服务端把库中原始行打上新值后**按整行校验**，跨字段的规则不会被逐格改写绕过，`DataProxy` 与操作日志和表单提交一致
- **两级开关**：模型级 `@Power(cellEdit)`、字段级 `@Edit(cellEdit)`，账号、角色编码、密钥这类字段框架已默认关闭

详见 [@Power → cellEdit 单元格编辑](/zh/annotation/power#celledit-单元格编辑)。

### 行内交互

- **拖拽排序**：模型配置 [@DragSort](/zh/annotation/drag-sort) 后，行首出现拖拽手柄，直接拖动调整顺序并保存
- **行操作**：查看、编辑、删除与自定义 [@RowOperation](/zh/annotation/row-operation) 按钮
- **分页记忆**：每页条数、当前视图（表格 / 卡片 / 甘特等）按模型记住

::: details 每个模型在本地记住了什么
浏览器 localStorage 中以 `erupt.<模型名>` 为键保存：

| 字段 | 含义 |
| --- | --- |
| `columns` | 各列的显隐、宽度、固定位置 |
| `columnOrder` | 列顺序 |
| `treeWidth` / `treeCollapsed` | 左侧树宽度与折叠状态 |
| `aiPanelOpen` / `aiPanelWidth` | AI 面板开关与宽度 |
| `searchCollapsed` / `searchFieldsCollapsed` / `searchOperators` | 搜索区折叠状态与各字段选用的操作符 |
| `pageSize` | 每页条数 |
| `visIndex` | 当前视图索引 |

这些只存在于当前浏览器，不会上传服务端，也不影响其他用户。
:::

## 弹窗与表单

![可拖拽弹窗](/ui/draggable-modal.png)

- **弹窗可拖拽**：新增 / 编辑、引用选择、子表、附件选择等全部弹窗均可按住标题栏拖动，挪开后仍能看到底层表格数据对照填写
- **[分步表单](/zh/annotation/form-steps)**：字段多时按 DIVIDE 分割线拆成向导式步骤
- **输入辅助**：输入框左侧一键复制当前值，右侧是 [表单 AI 写作助手](/zh/modules/erupt-ai/writing-assistant)，下方实时显示字数 / 上限
- **代码与富文本**：代码编辑器、Markdown、富文本均支持全屏编辑与复制
- **附件拖拽**：多附件字段可拖拽调整顺序

### 表单面板 <Badge type="tip" text="v2.3.0+" />

新增 / 编辑 / 查看记录的表单统一为一个**表单面板**，有三种形态，可在面板标题栏或页面配置抽屉的「详情弹窗形态」中切换，切换时已加载的表单与未保存的输入原样保留：

| 形态 | 值 | 说明 |
| --- | --- | --- |
| 中间弹窗 | `center` | 居中浮动对话框，可拖拽（默认） |
| 侧边面板 | `side` | 停靠右侧的面板，宽度可拖拽并记忆（整行布局的表单单独记忆）；查看态下不遮挡列表点击，切换记录时面板复用 |
| 全屏 | `full` | 占满整个窗口，适合字段多、带子表的表单 |

站点默认值由 `app.js` 的 `theme.formPanelMode` 指定，用户的选择保存在浏览器中并优先生效。

标题栏集中了对当前记录的操作：

- **上一条 / 下一条**：在列表范围内逐条浏览并显示「n / 总数」，到边界时自动翻页
- **查看 ↔ 编辑**：就地切换，不必关掉再打开
- **复制链接**：复制带 `?id=<主键>` 的深链接，打开该表格路由时自动弹出这条记录的面板（多标签页复用已打开的标签时同样生效）
- **删除**：气泡确认后删除当前记录，面板跳到相邻记录或关闭
- **AI 助手**：以当前模块与记录值为上下文打开 AI 对话（需 [erupt-ai](/zh/modules/erupt-ai/)）
- **更多**：打印（需 [erupt-print](/zh/modules/erupt-print)，且模型未以 `@Power(print = false)` 关闭）
- **评论**：打开这条记录的评论流（需 [erupt-comment](/zh/modules/erupt-comment)）

关闭面板、切换记录或退出编辑时，若有未保存的修改会先询问是否放弃。**点击行查看详情**默认关闭——整行是一个很大的点击目标，上面还有链接、按钮与可编辑单元格；在页面配置抽屉中开启后，点击表格行即打开该记录的详情面板，行上显示手形光标，链接、按钮与可编辑单元格保留自己的行为。

## 安装为桌面应用（PWA） <Badge type="tip" text="v2.3.0+" />

Erupt 可作为渐进式 Web 应用安装到桌面（Chrome / Edge 地址栏的「安装」按钮）。安装后：

- **清单随站点配置生成**：应用名、描述与品牌色取自 `app.js` 的 `logoText` / `title` / `desc` 与顶栏颜色，无需维护 manifest 文件；`pwa.icon` 指定应用图标（svg，或 512px 以上的 png / jpg / webp），`pwa.shortcuts` 定义图标右键菜单中的快捷入口（支持 hash 路由）
- **顶栏即标题栏**：以 window-controls-overlay 模式运行时，顶栏充当可拖动的窗口标题栏（菜单与按钮照常可点），自动避开系统窗口按钮；抽屉、侧边表单面板与通知从顶栏下方开始
- **窗口颜色跟随顶栏**：浏览器 `theme-color` 从实际绘制的顶栏读取（登录页读页面底色），弹窗 / 抽屉遮罩与锁屏出现时同步变暗，窗口按钮四周的颜色始终与页面一致
- **站点图标**：`faviconPath` 可指定 ico / png / svg 任意格式的浏览器标签图标，预加载阶段即生效，不会先闪一下默认图标；运行时可调用 `window.eruptApplyFavicon` 更换

配置项见 [前端配置](/zh/guide/config-frontend)。
