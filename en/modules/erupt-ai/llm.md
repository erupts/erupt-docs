# Configure LLMs

Register a model under **AI Manager → Language Model**: pick the provider, fill in the model name and API domain, and paste the API key issued by the provider.

<img src="/ai/llm-list.png" width="1770">

The form comes in two steps: **Basic Info** (model name, provider, model, API domain) and **Settings** (runtime parameters). The provider dropdown ships adapters for ChatGpt, Claude, DeepSeek, Doubao, Fireworks, GLM, Gemini, Grok and more, and anything speaking the OpenAI-compatible protocol works too.

<img src="/ai/llm-config.png" width="1770">

Hit **Test Model** in the form to check connectivity, or click the icon in the list to try a conversation.
