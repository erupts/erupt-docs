# Connect External MCP Servers

Mount external MCP Servers into erupt and the model can call their tools mid-conversation — driving a browser, working with desktop files, reaching third-party services — mixed freely with erupt's own Tools.

:::info
Full MCP protocol support: once connected, any MCP can be operated from inside the Erupt platform.
:::

For the other direction — exposing erupt's AI Tools to Cursor, Claude Code and friends — see [Expose Erupt as an MCP Server](/en/modules/erupt-ai/mcp-server).
