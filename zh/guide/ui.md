# 界面与交互

Erupt 的界面由注解生成，但**用起来顺不顺手**不靠注解——下面这些能力开箱即有，无需任何配置，且大多按用户、按模型记在浏览器本地，下次打开还是你上次的样子。

## 外观设置

点击右上角 ⚙️ 打开 **页面配置** 抽屉，所有改动实时生效：

![页面配置](/ui/page-config.png)

### 外观

| 配置 | 说明 |
| --- | --- |
| 主题色 | 18 色预设 + 自定义取色器，一键重置回默认 `rgb(22, 119, 255)`。Brutalist 与 Terminal 自带色板（粉彩 / 荧光），各自单独记忆，切换皮肤时自动换到对应色板 <Badge type="tip" text="v2.4.0+" /> |
| 顶栏色 | 跟随主题 / 跟随主题色 / 预设色 / 自定义取色器；Brutalist 与 Terminal 皮肤的顶栏属于皮肤语言的一部分，不提供此项 |
| 配色方案 | 浅色 / 深色 / 跟随系统（跟随系统随 OS 实时切换） |
| 紧凑模式 | 缩小控件间距，一屏放下更多内容，可与深色任意组合 |
| 皮肤 | 默认 / Classic / Workspace / Material / Liquid Glass（液态玻璃）/ Brutalist / Terminal，七者互斥；2.3.0 起选择器改为带缩略图的平铺网格 <Badge type="tip" text="v2.3.0+" /> |
| 导航配色 | 仅 Workspace 皮肤：32 套浅色 / 深色框架预设 <Badge type="tip" text="v2.3.0+" /> |

除默认皮肤外，较早加入的两款：

- **Brutalist**：新粗野主义风格——暖白画布、粗黑描边、硬质偏移投影、直角与糖果色块，2.3.0 起按 raft.build 风格重绘；自带粉彩色板，单独记忆，顶栏样式属于皮肤的一部分
- **Liquid Glass**：液态玻璃——侧边栏是一块带背景模糊与高光边缘的半透明玻璃面板，悬浮在环境色场之上

2.3.0 新增两款 <Badge type="tip" text="v2.3.0+" />：

- **Workspace**：Slack / 飞书 / 钉钉式的工作台外壳——顶栏与侧边栏共用一块品牌色调的框架，内容区以圆角卡片浮在其上。框架配色有 32 套浅色 / 深色预设（浅色框架会自动把导航文字翻成墨色），站点默认值由 `theme.workspaceFrame` 指定，不设则从主题色推导；登录页在此皮肤下也套用同一框架
- **Classic**：Ant Design Pro 经典外壳——深蓝侧边栏 + 白色顶栏，顶部菜单模式下深蓝转移到顶栏

2.4.0 再添两款 <Badge type="tip" text="v2.4.0+" />：

- **Material**：Material 3 / Google Workspace（Gmail）式外壳——顶栏、菜单列与四周留白是一整块品牌色调的「容器面」，页面是嵌在其中的圆角白色纸面，没有边框与接缝；菜单当前行是胶囊形，所有色调都从运行时主题色调和而来，换一个主题色整个外壳随之重新着色
- **Terminal**：荧光控制台——黑色画布、等宽字体、直角、无阴影，面板之间以虚线分隔；全站只有一种颜色，即主题色，皮肤自带 CRT 荧光色板（P1 绿为默认，另有琥珀、青、品红、白等），存放在独立的记忆槽位中，不会污染其他皮肤的主题色；浅色模式下变为纸带电传打字机：暖色纸面 + 加深为墨色的同一荧光色；顶栏色选择器在此皮肤下隐藏

`app.js` 中的 `theme`（`primaryColor`、`headerColor`、`dark`、`compact`、`skin`、`workspaceFrame`、`menuMode`、`menuGroups`、`formPanelMode`、`loginLayout`）和 `tabReuse` 是**系统默认值**，见 [前端配置](/zh/guide/config-frontend)；用户在此抽屉里的选择保存在浏览器 localStorage 中并优先生效。清除缓存即回到系统默认；`theme.customizable: false` 则让品牌相关项不再接受用户选择。
:::

## 登录页布局 <Badge type="tip" text="v2.3.0+" />

登录页提供五种布局，可在登录页顶部导航中切换（选择保存在浏览器 localStorage 的 `login-layout` 中；`theme.customizable: false` 时隐藏切换入口），站点默认值由 `app.js` 的 `theme.loginLayout` 指定：

| 布局 | 值 | 说明 |
| --- | --- | --- |
| 居中卡片 | `center` | 登录卡片居中浮在插画之上（默认） |
| 侧边面板 | `cover` | 插画铺满全屏，表单停靠右侧的 440px 面板 |
| 宽卡分栏 | `wide` | 一张 800px 宽卡，左侧品牌区（Logo 在上、标题在下），右侧表单 |
| 壁纸玻璃 | `wallpaper` | 图片铺满全屏，中间一张毛玻璃卡片 |
| 品牌满屏 | `poster` | 品牌名作为海报级大标题，小卡片位于右下角 |


居中卡片（`center`）与侧边面板（`cover`），均配置了 `theme.loginBackground` 自定义登录图片：

![登录页：居中卡片](/ui/login-center.png)

![登录页：侧边面板](/ui/login-cover.png)

- 窗口宽度小于 992px 时所有布局都收拢为居中卡片
- `theme.loginBackground` 可指定一张图片替换所有布局中的默认插画（自动加暗角保证品牌与版权可读）；图片加载失败时回落到默认插画，不会出现空白页
- Workspace 皮肤下登录页套用与工作台相同的框架配色
- 安装 [erupt-sso](/zh/modules/erupt-sso) 后，登录卡片自动出现单点登录按钮：3 个以内的认证源横排显示名称，更多则收为带提示的圆形图标

## 布局可伸缩

![侧边栏宽度拖拽](/ui/sidebar-resize.png)

| 区域 | 可拖拽范围 | 记忆方式 |
| --- | --- | --- |
| 侧边栏菜单 | 150px ~ 400px | 全局记忆，菜单文字再长也能一次看全 |
| 表格左侧树面板 | 120px ~ 600px | **按模型**记忆，可整体折叠 |
| AI 助手面板 | 拖拽调整 | 按模型记忆开关状态与宽度 |

侧边栏底部还有一排工具：刷新菜单、**定位当前菜单**（展开并滚动到当前所在的菜单项）、**最近访问**（与首页共用同一份记录）、**关键字过滤**（就地筛选菜单树）<Badge type="tip" text="v2.3.0+" />。2.3.0 起整棵菜单树不再支持拖拽排序（顺序以服务端为准，收藏夹仍可拖拽），菜单模式的切换入口也统一移到了页面配置抽屉。顶部的搜索框可直接**搜索菜单**，输入关键字后按路径层级展示结果，回车直达。

### 菜单分组标题 <Badge type="tip" text="v2.4.0+" />

侧边栏按**模块分组**显示分节标题：一级菜单按排序值切成若干节，连续一段属于同一模块分组的根菜单构成一节，节首显示分组名——**业务**（报表、流程、通知、打印、文件等）、**AI**、**开发工具**、**运维**、**数据源**。平台基础模块（用户、权限、安全、模板）与用户自建的菜单不加标题；夹在某一组中间的自建菜单归入该节。顺序仍只由菜单的排序值决定：管理员改排序即可整节移动，或把一个菜单挪进某一节。

分组来自各模块在注册时声明的 `ModuleGroup`，已安装模块按同样的分组列在「系统管理」下新增的**模块中心**页面中，见 [菜单管理](/zh/modules/erupt-upms/menu)。不想要标题时，在页面配置抽屉关闭「菜单分组标题」，或在 `app.js` 中设置 `theme.menuGroups: false` 作为站点默认。

另外，分栏 / 双列 / 顶栏双行模式下展开另一个分类的子菜单时，不再自动跳回当前路由所属的分类。

## 表格能力

![表格列配置](/ui/table-columns.png)

### 列控制

点击表格工具栏的 ▦ 按钮打开列面板：

- **显隐**：勾选控制每列是否展示
- **排序**：拖拽左侧手柄调整列顺序
- **固定**：图钉按钮在「固定左侧 → 固定右侧 → 不固定」间循环
- **列宽**：直接拖拽表头分隔线调整，面板底部「重置列宽」一键还原

以上设置**按模型**保存在本地，换页面互不影响。

### 工具栏

| 功能 | 说明 |
| --- | --- |
| 刷新 / 自动刷新 | 手动刷新，或设置 10s / 30s / 1min / 5min 自动刷新，开启时按钮高亮 |
| 全屏 | 表格区域全屏展示 |
| 查询 | 展开 / 收起搜索区，搜索条件与操作符按模型记忆 |
| 排序 | 多字段排序配置 |
| 批量编辑 | 选中多行后出现：选一个字段、填一个值，一次写到所有选中行，见 [批量编辑](#批量编辑) <Badge type="tip" text="v2.4.0+" /> |
| 打印 / 打印布局 | 选中一行后打印该记录（内置排版或打印模板）；「打印布局」管理本模型的打印模板。仅对可读取记录详情的用户显示，见 [打印设置](#打印设置) |
| 导入 / 导出 | Excel 导入、下载模板（需 `@Power` 开启）；导出按钮默认输出 Excel，右侧下拉可选服务端提供的其他格式，见 [导出格式与合计栏](#导出格式与合计栏) <Badge type="tip" text="v2.4.0+" /> |
| 复制行 | 选中一行后一键复制为新增表单，主键已清空，适合录入结构相近的数据 |

| AI | 打开右侧 AI 助手面板，对当前模型提问 |

### 搜索与视图

- **操作符可切换**：搜索区每个字段前有操作符下拉（等于 / 模糊 / 大于 / 区间 / 多选等），选择按模型记忆；服务端可用 [@Search(lockOperator)](/zh/annotation/search) 锁死不允许切换
- **多视图**：同一模型可配置表格之外的[看板](/zh/annotation/vis-board)、[日历](/zh/annotation/vis-calendar)、[卡片](/zh/annotation/vis-card)、[甘特图](/zh/annotation/vis-gantt)，顶部切换，当前视图按模型记住
- **树表联动**：[@LinkTree](/zh/annotation/link-tree) 配置后左侧出现树形导航，点击节点过滤右侧表格，树面板可拖拽宽度、可整体折叠

### 单元格呈现

表格单元格按 [@View(type)](/zh/annotation/view) 渲染，其中这些是可交互的：图片点击放大预览、附件弹层查看与下载、二维码、进度条、颜色块、Markdown / HTML 富文本、布尔与选择项标签；超长文本自动省略，悬浮查看完整内容。

2.3.0 起 <Badge type="tip" text="v2.3.0+" />：

- **头像列**：`@View(type = ViewType.AVATAR)` 渲染 32px 圆形缩略图（详情页 120px），为空时显示人形占位，用户表的头像即以此方式展示
- **单元格换行**：模型配置 [@Layout(tableTruncate = false)](/zh/annotation/layout#tabletruncate-单元格换行) 后，超出列宽的内容换行显示而不是省略号，操作列按钮再多也全部可见
- **空布尔值**：布尔字段为 null 时单元格留空，不再渲染一个空标签

### 多维表格编辑 <Badge type="tip" text="v2.2.0+" />

双击单元格（或点击单元格上的编辑图标）即可就地修改一个字段，不必打开行表单——像用多维表格一样改数据。

![单元格编辑](/ui/cell-edit.png)

- **就是表单里那套组件**：浮层用的是行表单同一个编辑组件，值转换、校验、引用选择器行为完全一致，复制按钮、AI 写作助手、字数统计一并具备
- **整行校验**：服务端把库中原始行打上新值后**按整行校验**，跨字段的规则不会被逐格改写绕过，`DataProxy` 与操作日志和表单提交一致
- **两级开关**：模型级 `@Power(cellEdit)`、字段级 `@Edit(cellEdit)`，账号、角色编码、密钥这类字段框架已默认关闭

详见 [@Power → cellEdit 单元格编辑](/zh/annotation/power#celledit-单元格编辑)。

### 批量编辑 <Badge type="tip" text="v2.4.0+" />

勾选多行后工具栏出现**批量编辑**按钮：在弹窗中选一个字段、填一个值，确定后所有选中行的该字段被设为同一个值。

- **同一套组件**：编辑器就是行表单里该字段的编辑组件，日期、选择、引用选择器与值转换都和表单一致；打开时为空，填入的值替换每一行原有的值
- **可选字段**：与单元格编辑的规则一致——表单中可见、可编辑、未以 `@Edit(cellEdit = false)` 关闭的字段；分割线、按钮、子表、多表单、树形标签等布局或集合类型不出现在列表中，依赖其他字段的引用选择器也不提供
- **逐行校验**：请求走批量单元格接口，每一行都经过与单元格编辑相同的校验、`DataProxy` 与操作日志；通过行级 `__power__` 收回编辑权的行会被跳过，一行都不可改时直接提示
- **开关**：模型可编辑时默认提供，`@Power(batchEdit = false)` 收回，见 [@Power → batchEdit](/zh/annotation/power#batchedit-批量编辑)

### 导出格式与合计栏 <Badge type="tip" text="v2.4.0+" />

- **导出格式**：导出按钮直接输出 Excel；按钮右侧的 `…` 下拉列出服务端注册的全部格式——Excel、CSV、JSON、JSON Lines、Markdown，每种一项，选中行有勾选时只导出勾选的行。导入模板始终是 Excel（带校验与提示）。自定义导出内容见 [DataProxy → excelExport](/zh/advanced/data-proxy-excel)
- **合计栏**：模型中有 [@View(statistic)](/zh/annotation/view) 列时，表格下方出现一条合计栏，每列一枚「列名 · 合计值」的小标签。合计由服务端按当前查询条件计算，单独请求、单独渲染，不影响数据行的加载与刷新

### 行内交互

- **拖拽排序**：模型配置 [@DragSort](/zh/annotation/drag-sort) 后，行首出现拖拽手柄，直接拖动调整顺序并保存
- **行操作**：查看、编辑、删除与自定义 [@RowOperation](/zh/annotation/row-operation) 按钮
- **分页记忆**：每页条数、当前视图（表格 / 卡片 / 甘特等）按模型记住

::: details 每个模型在本地记住了什么
浏览器 localStorage 中以 `erupt.<模型名>` 为键保存：

| 字段 | 含义 |
| --- | --- |
| `columns` | 各列的显隐、宽度、固定位置 |
| `columnOrder` | 列顺序 |
| `treeWidth` / `treeCollapsed` | 左侧树宽度与折叠状态 |
| `aiPanelOpen` / `aiPanelWidth` | AI 面板开关与宽度 |
| `searchCollapsed` / `searchFieldsCollapsed` / `searchOperators` | 搜索区折叠状态与各字段选用的操作符 |
| `pageSize` | 每页条数 |
| `visIndex` | 当前视图索引 |

这些只存在于当前浏览器，不会上传服务端，也不影响其他用户。
:::

## 弹窗与表单

![可拖拽弹窗](/ui/draggable-modal.png)

- **弹窗可拖拽**：新增 / 编辑、引用选择、子表、附件选择等全部弹窗均可按住标题栏拖动，挪开后仍能看到底层表格数据对照填写
- **[分步表单](/zh/annotation/form-steps)**：字段多时按 DIVIDE 分割线拆成向导式步骤
- **输入辅助**：输入框左侧一键复制当前值，右侧是 [表单 AI 写作助手](/zh/modules/erupt-ai/writing-assistant)，下方实时显示字数 / 上限
- **代码与富文本**：代码编辑器、Markdown、富文本均支持全屏编辑与复制
- **附件拖拽**：多附件字段可拖拽调整顺序

### 表单面板 <Badge type="tip" text="v2.3.0+" />

新增 / 编辑 / 查看记录的表单统一为一个**表单面板**，有三种形态，可在面板标题栏或页面配置抽屉的「详情弹窗形态」中切换，切换时已加载的表单与未保存的输入原样保留：

| 形态 | 值 | 说明 |
| --- | --- | --- |
| 中间弹窗 | `center` | 居中浮动对话框，可拖拽（默认） |
| 侧边面板 | `side` | 停靠右侧的面板，宽度可拖拽并记忆（整行布局的表单单独记忆）；查看态下不遮挡列表点击，切换记录时面板复用 |
| 全屏 | `full` | 占满整个窗口，适合字段多、带子表的表单 |

站点默认值由 `app.js` 的 `theme.formPanelMode` 指定，用户的选择保存在浏览器中并优先生效。

标题栏集中了对当前记录的操作：

- **上一条 / 下一条**：在列表范围内逐条浏览并显示「n / 总数」，到边界时自动翻页
- **查看 ↔ 编辑**：就地切换，不必关掉再打开
- **复制链接**：复制带 `?id=<主键>` 的深链接，打开该表格路由时自动弹出这条记录的面板（多标签页复用已打开的标签时同样生效）
- **删除**：气泡确认后删除当前记录，面板跳到相邻记录或关闭
- **AI 助手**：以当前模块与记录值为上下文打开 AI 对话（需 [erupt-ai](/zh/modules/erupt-ai/)）
- **变更历史**：在抽屉中查看这条记录的每次改动并可回滚（需 [erupt-revision](/zh/modules/erupt-revision)，且模型未以 `@Power(revision = false)` 关闭；表格行上没有这个入口）<Badge type="tip" text="v2.4.0+" />
- **更多**：打印（需 [erupt-print](/zh/modules/erupt-print)，模型未以 `@Power(print = false)` 关闭，且当前用户拥有 `edit` 或 `viewDetails` 权限之一），见下文 [打印设置](#打印设置)
- **评论**：打开这条记录的评论流（需 [erupt-comment](/zh/modules/erupt-comment)）

关闭面板、切换记录或退出编辑时，若有未保存的修改会先询问是否放弃。**点击行查看详情**默认关闭——整行是一个很大的点击目标，上面还有链接、按钮与可编辑单元格；在页面配置抽屉中开启后，点击表格行即打开该记录的详情面板，行上显示手形光标，链接、按钮与可编辑单元格保留自己的行为。

### 打印设置 <Badge type="tip" text="v2.4.0+" />

安装 [erupt-print](/zh/modules/erupt-print) 后，表格工具栏与记录面板的「更多」菜单都可以打印一条记录。模型没有配置打印模板时打开**内置打印预览**，预览顶部是一条设置栏，改动即时反映在预览中并记在浏览器中，下次打印任何模型时沿用，流程审批单的默认打印也共用这份设置：

| 设置 | 说明 |
| --- | --- |
| 表单样式 | 标签在上 / 标签在左 |
| 每行列数 | 1 ~ 4 列；整行布局（`FormSize.FULL_LINE`）的模型默认 1 列，其余默认 3 列 |
| 边框 / 线框颜色 | 单元格边框开关及颜色 |
| 字号 | 10 ~ 24 px |
| 标题 | 是否在表单上方打印标题（默认取当前菜单名） |
| 纸张大小 / 方向 | A4 / A3 / A5 / Letter / 自动，纵向或横向 |
| 页边距 | 0 ~ 50 mm |

预览里一对多、多对多与多表单字段打印成一张子表（取其表格列），树形标签字段打印为勾选节点的名称，组合字段作为一个带标题的分节。真正打印时页面被写入一个隐藏的 iframe，带上站点样式但去掉深色 / 紧凑主题，因此排版按纸张宽度重排而不是照搬屏幕像素。配置了打印模板时先弹出「选择打印排版」列表，「默认排版」即内置预览，其余按模板输出。

## 抽屉 <Badge type="tip" text="v2.3.0+" />

全站抽屉统一为 44px 高的标题栏（与页面头部等高）：标题居左，关闭按钮为右侧小方块。AI 对话、通知中心、Cube 下钻、流程发起、流程图、TPL 模板、审批详情等抽屉均可拖拽内侧边缘调整宽度，并各自记住上次拖到的尺寸。

## 锁屏与个人资料 <Badge type="tip" text="v2.3.0+" />

顶栏头像菜单新增三项：**个人信息**（修改自己的头像与昵称，保存后顶栏即时更新）、**双因素认证**（绑定 TOTP 动态口令）与**锁屏**（整窗遮罩盖住当前页面，标签页保持原样，输入密码解锁，刷新页面仍保持锁定）。个人信息与锁屏仅对平台账号显示，租户会话不显示。详见 [用户管理 → 个人资料与锁屏](/zh/modules/erupt-upms/user#个人资料与锁屏)。

![锁屏](/ui/lock-screen.png)

锁屏遮罩的角落有一组**外观控件** <Badge type="tip" text="v2.4.0+" />：浅色 / 深色切换、皮肤选择与主题色（预设色块、自定义取色与重置）。它们与页面配置抽屉共用同一份保存的选择，解锁后外观保持不变；皮肤与主题色属于品牌项，`theme.customizable: false` 时隐藏，仅保留浅色 / 深色切换。

## 安装为桌面应用（PWA） <Badge type="tip" text="v2.3.0+" />

Erupt 可作为渐进式 Web 应用安装到桌面：清单随站点配置生成，顶栏充当可拖动的窗口标题栏，`pwa.icon` / `pwa.shortcuts` / `faviconPath` 可定制。详见 [安装为桌面应用（PWA）](/zh/guide/pwa)。
