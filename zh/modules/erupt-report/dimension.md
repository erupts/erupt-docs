# 参照维度

报表中存在动态的条件列表（下拉框、下拉树、级联等），通过参照配置的方式统一定义，由 SQL 返回的结果生成列表或者树。

![](/report/dimension-list.png)

## 配置项说明

| 配置项 | 说明 |
| --- | --- |
| 名称 | 参照维度名称 |
| 数据源 | 参照 SQL 执行所在的数据源，不选则使用默认数据源 |
| 处理类 | 可绑定[报表处理类](./handler)动态处理参照 SQL 与结果 |
| 参照 SQL | 生成列表或树的查询语句 |

## SQL 返回列约定

不同的维度类型对 SQL 返回列的要求不同：

| 维度类型 | 返回列 |
| --- | --- |
| 列表参照（单选、多选、单选框、复选框） | 两列：查询值 id / 显示名 label |
| 树型参照（单选树、多选树、级联） | 三列：查询值 id / 显示名 label / 父 ID pid，pid 为空即根节点 |
| 表格参照（单选表格、多选表格） | 2~N 列：第一列为查询值（不在前端展示），其余列均展示 |

## 使用

**报表配置 → 查询维度 → 维度类型**

选择任意**参照**类维度类型，再关联参照维度即可
