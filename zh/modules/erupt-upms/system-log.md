# 系统日志

不登服务器、不开终端，在浏览器里实时查看应用日志。

<img src="/upms/system-log.png" width="1000">

## 工作方式

- 启动时向 Logback 或 Log4j2 注册一个 Appender，把应用输出的每一行日志复制到内存队列中，超过容量后丢弃最早的行。
- 页面每 1.5 秒拉取一次增量，以 xterm 终端方式渲染：日志级别着色、超链接可点击、支持搜索，窗口尺寸变化自动重排。
- 只保留最近 N 行且不落盘，不会影响原有日志文件与日志框架配置。

## 配置

```yaml
erupt:
  log-track: true            # 是否开启日志采集，默认 true
  log-track-cache-size: 1000 # 内存中保留的最大行数
```

排查问题时可临时调大 `log-track-cache-size`；它只影响内存占用，每行日志在内存中约占其文本长度大小。

## 权限

系统日志是一个模板类型的菜单，受菜单权限控制，只授予运维或管理员角色。日志中可能包含 SQL、参数与堆栈信息，不建议对普通用户开放。

## 集群与多节点

单机部署直接使用。使用 [erupt-cloud](/zh/modules/erupt-cloud) 时，每个节点的日志可在云端「节点管理」中以同样的方式查看，无需逐台登录。
