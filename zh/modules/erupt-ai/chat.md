# AI 对话

erupt-ai 内置一个完整的对话工作台：Markdown / 代码 / Mermaid / 公式实时渲染，支持图片输入与多模型切换，工具调用与智能体编排在对话中自动发生。

## 沉浸式 AI 对话

:::tip
与大模型自然对话，所见即所得——代码高亮、Mermaid 图表、数学公式实时渲染，支持工具自动调用与智能体编排，让每一次交互都触达 AI 的真实能力边界。
:::

左侧是会话列表，可重命名、删除与检索历史；底部一行固定着**模型**、**专家**与 **Auto tool call** 开关，随时切换本轮用哪个模型、以什么身份作答、是否允许自动调用工具。

## 多模态对话 <Badge type="tip" text="v2.2.0+" />

对话输入栏支持上传图片，与文本一并发给大模型——截图问诊、单据识别、UI 稿转代码这类场景不必再把内容誊写成文字。

| 能力 | 说明 |
| --- | --- |
| 上传方式 | 点击回形针按钮选择文件，或直接在输入框中 `Ctrl/Cmd + V` 粘贴剪贴板图片 |
| 预览 | 发送前显示缩略图，点击可放大查看 |
| 存储 | 经 `POST /ai/chat/upload-image` 由 `EruptFileService` 存储，仅放行图片扩展名；路径数组随消息持久化到 `e_ai_chat_message.images` |
| 历史上下文 | 重建会话上下文时图片同样解析为 base64 一并带上，追问不会「失忆」 |
| 重新生成 / 编辑重发 | 携带原有图片附件 |
| 远程附件 | 本地与 `AttachmentProxy` 托管的远程附件都能解析 |

:::warning 需要模型本身支持视觉输入
多模态请求走的是绕过提示词模板的 `List<Content>` 通道，仅在消息确实带图片时启用。选用的模型若不具备视觉能力，请求会被模型服务商拒绝——请在 [大模型管理](/zh/modules/erupt-ai/llm)中选择支持视觉的模型。
:::

### 模型选择器

输入栏右侧提供模型下拉框，可随时切换本轮使用的模型。仅在**存在多个已启用模型**时显示；通过 `?llm=` 锁定模型的场景（如模型测试）下隐藏，避免暴露被锁定的模型。候选列表由 `GET /ai/chat/llms` 下发，**不包含任何密钥信息**。

对话不止在 AI Chat 页面：任意页面右侧都能唤起 AI 面板，带着当前页面的上下文提问，上传的图片以缩略图形式留在消息里。
