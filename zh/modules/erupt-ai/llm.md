# LLM 接入

在 **AI Manager → 大模型** 中登记模型：选择服务商、填写模型名与 API 域名，API Key 到对应大模型官网申请即可。

<img src="/ai/llm-list.png" width="1770">

新增表单分两步：**基础信息**（模型名称、服务商、模型、API 域名）与 **运行参数**。服务商下拉内置 ChatGpt、Claude、DeepSeek、Doubao、Fireworks、GLM、Gemini、Grok 等适配器，选定后填入官网申请的 Key 即可；OpenAI 兼容协议的服务同样可以接入。

<img src="/ai/llm-config.png" width="1770">

填完可直接点 **Test Model** 验证连通性，也可在列表中点击对应图标测试大模型会话。
