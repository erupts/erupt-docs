# 在线用户

实时列出当前持有有效 Session 的用户，并支持一键强制下线。

## 数据来源

在线列表不是独立的表，而是**登录日志与 Session 存储的交集**：只有 token 仍存在于 Session 中的登录记录才会出现。Session 存于本地内存或 Redis（`erupt.redis-session`，见[参数配置](/zh/guide/configuration)），两种模式下均可用。用户主动退出、Session 过期或被强制下线后即从列表消失。

## 列表字段

| 字段 | 说明 |
| --- | --- |
| 账号 / 登录时间 | 支持模糊搜索与按时间范围筛选 |
| IP 地址 / IP 来源 | 来源解析为「国家 \| 省份 \| 城市 \| 运营商」，离线库解析，无网络依赖 |
| 操作系统 / 浏览器 / 设备类型 | 由 User-Agent 解析 |

列表只读且支持导出。

## 强制下线

行操作**强制下线**会删除该 token 对应的全部 Session 键，用户下一次请求即被判定为未登录并跳回登录页。典型场景：

- 发现异常地区 / 设备登录，先踢下线再处理账号。
- 修改了某人的角色权限，要求立即生效。
- 锁定账号后清理其存量会话。同一账号允许多端登录，每个端一条记录，可分别处理。
